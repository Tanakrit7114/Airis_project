# JARVIS Adaptive Response + Auto-Continuation

เวอร์ชันนี้เพิ่มระบบตอบตามความเหมาะสมและต่อคำตอบอัตโนมัติเมื่อโมเดลหยุดเพราะชนขีดจำกัดการสร้างข้อความ

## พฤติกรรม
- คำถามง่าย: ตอบสั้นและตรง
- คำถามวิชาการ/วิเคราะห์: เพิ่มรายละเอียดตามความซับซ้อน
- สรุปเอกสาร/OCR: รักษาประเด็นสำคัญและโครงสร้าง
- หาก generation จบแบบ `length`/`max` หรือดูเหมือนถูกตัดกลางประโยค/รายการ/สมการ/code block ระบบจะขอให้โมเดลต่อคำตอบโดยไม่ทำซ้ำ
- จำกัด continuation เริ่มต้นที่ 2 รอบเพื่อป้องกัน loop และการตอบยาวเกินความจำเป็น

## Environment
```env
MAX_GENERATION_TOKENS=1536
MAX_CONTINUATIONS=2
CONTINUATION_MIN_RATIO=0.92
```

`MAX_CONTINUATIONS=0` เพื่อปิด auto-continuation

## หมายเหตุ
Auto-continuation ช่วยกรณีคำตอบถูกตัด แต่ไม่ได้รับประกันความสมบูรณ์ของเนื้อหาเชิงข้อเท็จจริง ควรใช้ร่วมกับ Memory/Search/OCR ตามเดิม
